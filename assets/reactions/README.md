# Картинки для реакцій

Кожна тема має свою теку, названу так само, як правило в
`src/reactions/rules.py`: `klitschko/`, `trump/`. Бот бере випадковий файл із
теки, коли в чаті згадують цю тему.

Підтримуються `.jpg`, `.jpeg`, `.png`, `.webp`, а також анімації `.gif` і `.mp4`
(регістр розширення не важливий).

**Картинки в репозиторій не потрапляють**: теки ігнорують і `.gitignore`, і
`.dockerignore`. Під git лишається лише цей README.

## Локально

Поклади файли в `assets/reactions/<тема>/`.

## У проді

Картинки лежать на томі Fly у `/app/data/reactions/<тема>/`, шлях задає
`REACTIONS_DIR` у `fly.toml`. Синхронізувати локальні теки з сервером:

    scripts/sync_reactions.sh          # усі теми
    scripts/sync_reactions.sh trump    # одна тема

Скрипт лише додає файли, яких на сервері ще немає. Зайві файли на сервері він
не видаляє, а тільки показує їх; видалити можна так:

    fly ssh console -C "rm /app/data/reactions/trump/<файл>"

Перезапускати бота не треба: теку перечитують при кожній реакції. На старті
бот пише в лог, скільки картинок бачить кожна тема.

## Реакція на тег людини

Бот відповідає гіфкою, коли в чаті тегають конкретну людину. Кого саме — задає
секрет на Fly, а не код: юзернеймам та ID людей не місце в публічному репозиторії.

    fly secrets set MENTION_REACTIONS="@some_username=folder_a,123456789=folder_a"

Ліворуч — юзернейм або Telegram ID, праворуч — тека з гіфками. Людину без
юзернейма тегають вибором зі списку учасників, і тоді Telegram передає її ID;
для такої людини вказуй ID. Ключі з однією текою — одне правило зі спільним
кулдауном (1 година на чат). Самотег і просто ім'я текстом без тегу не рахуються.

ID можна знайти в базі бота:

    SELECT DISTINCT user_id, full_name, username FROM messages WHERE full_name ILIKE '%імʼя%';

## Повітряна тривога

Окремо від тем є дві теки для `src/alerts/air_raid.py`: `air_alert/` (початок
тривоги) і `all_clear/` (відбій). Якщо тека порожня, бот надішле лише текст.

## Нова тема

1. Додай `ReactionRule` у `src/reactions/rules.py`.
2. Створи теку з тією ж назвою й поклади туди файли.
3. Задеплой код і запусти `scripts/sync_reactions.sh <тема>`.
